# Published data snapshot

This directory contains the real, read-only data snapshot used by the public GitHub Pages site. It is not placeholder or synthetic data.

## Snapshot scope

- `feed.json`: a lightweight index of all 5,115 collected records through 2026-07-09.
- `details/00.json` … `details/3f.json`: 64 deterministic detail shards containing the corresponding real record bodies and type-specific payloads.
- `podcast_channels.json`: the three-channel production grouping used by the dashboard.
- `content_filter.json`: the production relevance snapshot used for grouping and low-relevance folding.

The feed covers all eight registered source types:

| Source type | Records |
| --- | ---: |
| `wechat` | 4,015 |
| `news` | 856 |
| `podcast` | 83 |
| `banhao` | 41 |
| `entity` | 30 |
| `entity_change` | 30 |
| `trademark` | 30 |
| `recruitment` | 30 |

Titles, source names, dates, summaries, available bodies and source links are retained from the collected records. The public export removes internal `raw_ref` values, private monitoring keywords, transcription task state and one invalid local placeholder-audio path. Collectors, credentials, cookies, local service configuration, raw/state/cache directories and administrative capabilities are not published.

This is a historical portfolio snapshot, not a live data service. Rights in third-party articles, audio, images, brands and platform material remain with their respective owners. Source links are retained for attribution where available.

The snapshot is generated by `scripts/export-public-snapshot.mjs` and validated by `scripts/verify-public-snapshot.mjs`; the Pages workflow refuses to deploy if index/detail integrity or the privacy gates fail.
